## Goal and background

Ship the first public version of handoff-kit: an offline-verifiable contract for
resuming an agent's work in a new conversation.

## Latest decisions and reasons

1. Standard library only. The gate must run in any CI without dependencies.
2. Hashes use LF_UTF8_v1 so Windows and Linux produce identical digests.
3. `prepared` may have empty remote ids; `committed` may not. Fail closed.

## Role, access and authorization boundary

The demo agent uses its own object-store credentials, injected by the operator.
No secret is ever written into a run directory.
