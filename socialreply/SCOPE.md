# Scope

Reusable multi-workspace customer-reply product: authorized comments/text messages, shared knowledge/policies, durable processing, adapters and an operator dashboard. No client-specific identity, budget, pricing or source case number is included.

Native Meta and LINE adapters; approved TikTok connector boundary; optional real OpenAI-compatible provider. No-key operation is explicitly non-LLM knowledge rules. Local HTTP E2E does not establish real provider access. No private-account crawling, advertising system, historical-post importer or full CRM.
