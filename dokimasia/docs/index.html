dokimasia

AI model vetting, in three gates. Leaderboards set expectations; money is spent only after live probing on your own stack.

Python 3.10+ License MIT Dependencies zero Status Sample

Why

Leaderboards tell you who is smart. Dokimasia tells you whether a model, on your endpoint, at your price, in your job, breaks in ways you cannot afford — then prices the survivors with measured token load, not estimates.

The gates

Gate 1

Tool call

The model must call the given function with the given arguments. Broken tool calls kill automation.

Gate 2

Contradiction

Two conflicting rules are given; the model must flag the conflict instead of answering anyway. A heterogeneous judge reviews what a literal grader cannot catch.

Gate 3

Strict JSON

The model must return exactly the required JSON. Promised JSON delivered as prose ruptures pipelines.

Fourth failure mode

Leadership

Delegation fit, gradeable acceptance criteria, failure handling, honest status. Excellent workers can be poor leads — this probe catches it.

The flow

candidates → select scans → Gate 1 · 2 · 3 → judge reviews the misses → token load measured → monthly cost at your volume → verdict: PASS, in budget → hire · FAIL → out, model not qualified · ERROR → out, fix the endpoint and re-run

ERROR and FAIL are different exits. An all-ERROR batch means fix the endpoint and re-run — never change the conclusion.
