Ledger Pipe

Monthly reporting with a source contract. Sources that break the contract stop the run, and the error names the source, the row and the column.

Python standard librarySingle machineNo networkAuthor self-test 12/12Sample data

The problem

Reporting fails because sources change shape, not because arithmetic is broken: a renamed column, an amount with a comma or a full-width digit, a blank row, a repeated key, an impossible date. Someone then reads the sheet line by line, and one bad row means redoing the table. So the product is the contract, not the report.

Boundaries

No system integration, no approval workflow, no web back end, no cloud, no accounts. Reads sources, writes only to its own output folder.

Run

python3 pipeline.py --data data/2026-08 --out out
python3 pipeline.py --data data/2026-09 --out out
python3 tests/run_tests.py
